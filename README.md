# Heart Disease Prediction & Classification Analysis

This repository contains a complete Data Science assignment focused on predicting heart disease risk using machine learning classifiers.

## Project Structure & Files:
- **`analysis.py`**: Python script for data cleaning, EDA, and training 7 classification models (Logistic Regression, Decision Tree, Random Forest, KNN, SVM, Naive Bayes, Gradient Boosting).
- **`predict_app.py`**: Interactive CLI application to predict heart disease risk for new patient data using the best trained model.
- **`Heart_Disease_Report.docx`**: Comprehensive assignment report including dataset description, charts, algorithm comparison, and findings.
- **`heart_model.pkl`**: Saved trained model file.
- **`model_comparison.csv`**: Raw performance results table of all models.
